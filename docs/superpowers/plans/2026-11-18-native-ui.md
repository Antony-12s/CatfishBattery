# Native UI rewrite: work split

Date: 2026-11-18. Integration branch: `feature/native-ui` (coordinator: Hermes).
Goal: replace the WebView pages (`BatteryWebPages.java`, `BatteryWindowStyle.java`) with native
Android views, and fix backlog items 1-4 (`docs/backlog.md`) inside the native version.

## Decisions for this round

- Backlog 1 (overlapping min/max markers): option 1. Hide the ▼/▲ cell markers while the cell
  spread is in the green band (≤ 2 mV, same threshold as the legend). Show them otherwise.
- Backlog 2: SOH moves from the Pack header badge into the schematic's HV PACK block, next to
  SOC / kW / V·A, formatted with `UiFormat.percent2` ("96.50 %"). Remove the header SOH badge.
  The JSON field is `soh.pct` in `BatteryDataHub.dataJson()`; `null` shows "SOH --".
- Backlog 3: every "time left" uses `UiFormat.duration` ("11 h 55 min", "45 min").
- Backlog 4: the schematic follows the theme. Night keeps the current dark look; day gets a light
  panel, blocks, wires, node boxes and labels with readable contrast.
- Backlog 5: this whole rewrite.

## Hard rules (AGENTS.md, DECISIONS.md)

- Keep the original 3D schematic: 1180x470 design space, block geometry, sensor anchors,
  energy-flow paths, the Schematic/Cells switch. Scale by both axes without distortion.
  Do not replace it with a SOC ring or heatmap.
- Navigation stays at the top (the existing native tab bar). Fit between the car's status bar and
  climate dock.
- Real or unavailable telemetry only. Missing values show "--", never 0 or a sample.
- No vehicle writes, no MQTT publish, no adb, no emulator, no car, no push. The coordinator owns
  the emulator and the car.
- Car display: 2560x1600 at density 160, so 1 dp = 1 px and 20 sp = 20 px. Size text for that.
- Package `com.catfish.battery` (pages need package-private `BatteryDataHub`). Java 17, minSdk 30.
  No new dependencies.

## Contract (already on the branch)

- `UiFormat`: `fixed`, `duration`, `percent2`, `power`. Use it for every number. Add a function
  there only if none fits, with a test.
- `UiPalette.of(context|night)`: day/night colours. Night accents may follow
  `BatteryWindowStyle.champagneNight()`.
- Data: all pages read `BatteryDataHub` JSON exactly as the WebView did
  (`dataJson`, `historyJson(range)`, `sessionsJson`, `settingsJson`, `saveSettings(json)`,
  `setCharger(start, charger)`, `resetTotals()`). Parse with `org.json`.
- Stubs with fixed names and signatures (owners replace the bodies):

| Class | Owner |
|---|---|
| `StatusPage`, `BatteryActivity` (WebView swap), cells grid, DECISIONS.md entry | opus-shell |
| `ChargingPage`, `HistoryPage`, `SettingsPage` and their tests | opus-pages |
| `PackSchematicView` (static drawing, markers, HV PACK/node text, day/night) | codex-art |
| `FlowOverlayView` (moving flow dots), `HistoryChartView`, `ChargeCurveView` | codex-motion |

Edit only files you own, plus new files you create with a name prefix that is clearly yours.
Need a change in someone else's file? Write it in your progress log and the coordinator routes it.
Port from the JS in `BatteryWebPages.java`: it is the reference for geometry, colours, thresholds
and text. Do not delete `BatteryWebPages.java` or `BatteryWindowStyle.java`; the coordinator
removes them at integration.
